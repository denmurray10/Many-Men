## 🌟 Overview

**Live Site:** [denmurray10.github.io/Many-Men](https://denmurray10.github.io/Many-Men)  
**Repository:** [github.com/denmurray10/Many-Men](https://github.com/denmurray10/Many-Men)

Many Men is a responsive, single-page website offering beginner-friendly information about men’s mental health, key warning signs, and practical ways to seek or offer support.

---

## 🧑‍💻 User Experience

### 🎯 Project Goals

- **External users:** Provide accessible, beginner-friendly information on men’s mental health, common issues, warning signs, and practical stress-management tips.
- **Site owner:** Build a calm, welcoming webpage with responsive layouts, card-based content, and form handling using HTML, CSS and Bootstrap.

### 👥 Target Audience

- Men who may be struggling with their mental health
- Friends, partners, colleagues, or family who want to offer support
- Tutors, assessors, and potential employers evaluating skills in HTML, CSS, Bootstrap, and JavaScript

### ✔️ Core User Stories (Met)

- Quickly understand the site’s purpose and experience a calm, supportive space
- Access beginner-friendly information on men’s mental health and support resources
- Recognise signs of struggle and know how to help
- Easy access to contact forms and external support links

### 🔜 Future User Stories (Planned)

- Prominent “In crisis?” panel/button for urgent help
- Save or print a self-help plan with chosen coping steps and contacts

## 🚀 Features

### Major Sections

| Section                | Feature                                                      |
|------------------------|-------------------------------------------------------------|
| Hero                   | Site title, tagline, call-to-action                         |
| Statistics             | Key UK men’s mental health stats                            |
| Warning Signs          | Card-based behavioral/emotional/physical sign explanations  |
| Guidance               | How to seek help or support others                          |
| Testimonials           | Recovery stories and quotes                                 |
| Resources              | Quick links—national helplines, legal info                  |
| Get Help Modal         | Guidance, validated contact form                            |
| Newsletter Modal       | Name/email sign-up, success alert                           |

## ⚠️ Known Issues & Limitations

- Minor layout quirks on very narrow screens
- Forms simulate submissions—do not store/send real data
- Accessibility testing with screen readers/ARIA for modals is planned
- Some transitions may be abrupt on lower-powered devices
